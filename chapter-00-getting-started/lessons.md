# Chapter 0 Lessons: Sounds, Spelling, and Your First French

This chapter assumes you have never studied French. Before you learn grammar, you need to be able to **look at a French word and make a reasonable sound come out of your mouth**. That single skill makes every later chapter easier, because from Chapter 1 onward you will be asked to read examples aloud.

Nothing here requires memorizing rules perfectly. Your goal is recognition and a confident first attempt.

## Learning objectives

You will learn to:

1. name the letters of the French alphabet and the five accent marks;
2. predict which letters at the end of a word are silent;
3. produce the main French vowel sounds, including the ones English does not have;
4. recognize and produce the four nasal vowels;
5. pronounce the consonants that behave differently from English;
6. apply elision (`le` -> `l'`) and hear liaison between words;
7. greet someone, say please and thank you, and choose between `tu` and `vous`;
8. count from 0 to 20 and give your name, age, and language level.

## Prerequisite quick check

None. This is the true starting point of the course.

You do **not** need to know any grammar words yet. If a term such as *noun*, *vowel*, or *syllable* is unfamiliar, open [`glossary.md`](glossary.md) in this chapter, which explains every grammar word used in the whole course in plain English.

## How to study this chapter

Pronunciation is a physical skill, not a fact to memorize. Read silently once, then **say every example out loud**. On the website, tap any French text to hear it spoken, then imitate it immediately. Copy the rhythm before worrying about individual sounds.

If a phrase goes past too quickly, drag **Speaking speed** in the sidebar down to about 60% and listen again: French runs its words together, and slowing it down is often the only way to hear where one ends and the next begins. Select the phrase and press **Slower** to hear it at half speed without changing your setting. Then put the speed back up to 90-100% and imitate it there. Practising only at slow speed teaches you to speak in a way no French person does, so treat slow playback as a magnifying glass, not a comfort zone.

Work through one unit per session. Return to this chapter briefly whenever a later chapter introduces words you cannot pronounce.

Every practice exercise in this course has a **Show answers** button folded underneath it, with a short explanation of the rule behind each answer. Leave it closed until you have committed to an answer out loud. Reading a model answer feels like learning, but the effort of producing your own one first is what actually makes it stick, and a mistake you make and then correct is worth more than a correct answer you only recognised.

> A useful loop for every example: **listen -> imitate immediately -> compare -> repeat twice**

## Unit 1: The Alphabet and the Accent Marks

### Core idea

French uses the same 26 letters as English, but the **letter names** differ, and five accent marks change either the sound or the meaning.

### The alphabet

Say each letter aloud. The third column is an approximate English respelling, not an exact sound.

| Letter | French name | Sounds roughly like |
|---|---|---|
| `a` | `a` | ah |
| `b` | `bé` | bay |
| `c` | `cé` | say |
| `d` | `dé` | day |
| `e` | `e` | uh |
| `f` | `effe` | eff |
| `g` | `gé` | zhay |
| `h` | `ache` | ash |
| `i` | `i` | ee |
| `j` | `ji` | zhee |
| `k` | `ka` | kah |
| `l` | `elle` | ell |
| `m` | `emme` | em |
| `n` | `enne` | en |
| `o` | `o` | oh |
| `p` | `pé` | pay |
| `q` | `qu` | kü |
| `r` | `erre` | air (throaty) |
| `s` | `esse` | ess |
| `t` | `té` | tay |
| `u` | `u` | ü |
| `v` | `vé` | vay |
| `w` | `double vé` | doo-bluh-vay |
| `x` | `ixe` | eeks |
| `y` | `i grec` | ee-grek |
| `z` | `zède` | zed |

Notice the trap: French `g` sounds like English "j," and French `j` sounds like the "s" in *measure*. English speakers reverse these constantly when spelling aloud.

### The five accent marks

| Accent | Name | Example | What it does |
|---|---|---|---|
| `é` | accent aigu | `café` | Makes a closed "ay" sound. |
| `è` | accent grave | `mère` | Makes an open "eh" sound. |
| `ê` | accent circonflexe | `fête` | Usually "eh"; often marks a lost letter s. |
| `ç` | cédille | `français` | Forces `c` to sound like "s" before `a`, `o`, `u`. |
| `ë` | tréma | `Noël` | Separates two vowels so each is pronounced. |

Two important points for beginners:

1. **An accent is part of the spelling, not decoration.** `ou` means "or" and `où` means "where." Leaving out an accent can create a different word.
2. **The grave accent on `à`, `où`, `là` does not change the sound.** It only distinguishes words that would otherwise look identical: `a` (has) versus `à` (to/at).

### Retrieval check

Without looking above:

1. Which accent turns `c` into an "s" sound?
2. Which two letters do English speakers most often swap when spelling aloud in French?
3. What is the difference in meaning between `ou` and `où`?

:::answer
1. **The cédille** — in `ça` and `français`, the mark under **c** makes it sound like **s** before **a**, **o**, or **u**.
2. **`g` and `j`** — French `g` is named with a sound like English **j**, while French `j` has the sound in English *measure*. English speakers often reverse them.
3. `ou` means **or**; `où` means **where**. The grave accent does not change the sound here, but it changes the word.

For the production task, answers vary. Spell your own name with French letter names, slowly first and then at normal speed. Mark yourself wrong only if you use English letter names, skip a letter, or cannot repeat the same spelling twice.
:::

### Production task

Spell your own first name aloud using French letter names. Repeat it twice at normal speed.

### Sentence usage practice

Read each line aloud twice, then cover it and write it from memory.

1. `Comment ça s'écrit ?` — How is that spelled?
2. `Ça s'écrit M-A-R-I-E.` — It is spelled M-A-R-I-E.
3. `J'habite à Paris.` — I live in Paris.
4. `Où est le café ?` — Where is the café?
5. `C'est une fête française.` — It is a French celebration.

:::answer
Use these as the model lines to check your memory copy. The goal is exact spelling, accents, apostrophes, and punctuation.

1. `Comment ça s'écrit ?` — `ça` needs the cedilla because **c** before **a** would otherwise sound hard. The apostrophe in `s'écrit` is required before the vowel sound.
2. `Ça s'écrit M-A-R-I-E.` — the same cedilla and elision appear again. The capital letters are being named, so the spelling matters more than a grammar rule here.
3. `J'habite à Paris.` — `je` becomes `j'` before the silent **h** of `habite`. The accent in `à` marks the word meaning to/at.
4. `Où est le café ?` — `où` needs the accent because without it, `ou` means or. French leaves a space before the question mark.
5. `C'est une fête française.` — `ce` becomes `c'` before `est`, and both `fête` and `française` need their accents.
:::


## Unit 2: Silent Letters

### Core idea

French writes more letters than it pronounces. Most words **end in a silent letter**. This is the single biggest shock for English speakers, and getting used to it early prevents months of over-pronouncing.

### Rule 1: Most final consonants are silent

- `petit` — small (you do not say the final t)
- `grand` — big (no final d)
- `vous` — you (no final s)
- `beaucoup` — a lot (no final p)

### Rule 2: The letters in CaReFuL are usually pronounced at the end

The English word **CaReFuL** is a memory aid for `c`, `r`, `f`, `l`:

- `avec` — with (c is pronounced)
- `bonjour` — hello (r is pronounced)
- `neuf` — nine (f is pronounced)
- `avril` — April (l is pronounced)

This is a helpful tendency, not a law. Common exceptions include `blanc` (white) and the `-er` verb ending, where the r is silent: `parler` — to speak.

### Rule 3: A final `-e` is silent

A final `-e` is not pronounced, but it **makes the consonant before it pronounced**. This is why gender agreement is audible:

| Masculine | Feminine | What you hear |
|---|---|---|
| `petit` | `petite` | "puh-TEE" vs "puh-TEET" |
| `grand` | `grande` | "grahn" vs "grahnd" |
| `français` | `française` | "frahn-SAY" vs "frahn-SEZ" |

This matters enormously from Chapter 1, where adjectives change for gender. The written `-e` is silent, yet it is exactly what makes the difference hearable.

### Rule 4: The verb ending `-ent` is silent

In the `ils`/`elles` form of a verb, `-ent` is completely silent:

- `il parle` and `ils parlent` sound **identical** — he speaks / they speak

You will meet this in Chapter 3. Do not try to hear a difference that does not exist; the subject word tells you the number.

### Rule 5: `h` is always silent

French never pronounces `h`:

- `l'hôtel` — the hotel
- `l'heure` — the hour

There are two kinds of `h` in spelling. A "mute h" behaves like a vowel and allows `l'` (`l'homme` — the man). An "aspirated h" blocks it (`le héros` — the hero). Both are silent; only the linking behavior differs. Learn the few aspirated-h words as you meet them.

### Retrieval check

Which letters do you pronounce in each word?

1. `salut`
2. `bonjour`
3. `chat`
4. `sportive`
5. `neuf`

:::answer
1. `salut` — pronounce the vowel sound, but not the final **t**. Most final consonants are silent.
2. `bonjour` — pronounce the final **r**. **R** is one of the CaReFuL letters that is often heard at the end.
3. `chat` — do not pronounce the final **t**. The **ch** sound is **sh**.
4. `sportive` — pronounce the **v** before the final silent **e**. A final **e** is silent, but it makes the consonant before it heard.
5. `neuf` — pronounce the final **f**. **F** is one of the CaReFuL letters.

The rule is not that final letters are always silent; the rule is that most final consonants are silent unless a common pattern, such as CaReFuL or a final **e**, wakes them up.
:::

2. `Il est petit, mais elle est petite.` — He is small, but she is small.
3. `Les étudiants parlent avec le professeur.` — The students speak with the teacher.
4. `L'hôtel est ouvert à neuf heures.` — The hotel opens at nine o'clock.
5. `Beaucoup de gens habitent ici.` — A lot of people live here.

:::answer
Use these as the model lines for the memory copy.

1. `Salut, ça va ?` — the final **t** in `salut` is silent, and French leaves a space before the question mark.
2. `Il est petit, mais elle est petite.` — `petit` has a silent final **t**; `petite` pronounces that **t** because of the final silent **e**.
3. `Les étudiants parlent avec le professeur.` — **-ent** on `parlent` is silent, but final **c** in `avec` is pronounced.
4. `L'hôtel est ouvert à neuf heures.` — `le` becomes `l'` before the silent **h** of `hôtel`; `neuf` usually keeps its final **f**.
5. `Beaucoup de gens habitent ici.` — the final **p** of `beaucoup` and final **s** of `gens` are silent.

Mark yourself wrong if you pronounced a silent final consonant that the sentence is meant to train.
:::

:::answer
Model memory check:

1. `Salut, ça va ?` — the final **t** in `salut` is silent. Keep the cedilla in `ça`; it forces the soft sound.

## Unit 3: Vowel Sounds

### Core idea

French vowels are **pure and short**. English vowels glide: the English "o" in *go* slides toward "oo." French vowels hold one steady position from start to finish. Keep your mouth still while the vowel lasts.

### Single vowels

| Spelling | Sound | Example | English |
|---|---|---|---|
| `a`, `à` | ah | `la table` | the table |
| `i`, `î`, `y` | ee | `il` | he |
| `o` | oh | `le mot` | the word |
| `u`, `û` | ü (see below) | `tu` | you |
| `e` (unstressed) | uh | `le` | the |
| `é` | ay (closed, no glide) | `le café` | the coffee |
| `è`, `ê`, `ai`, `ei` | eh (open) | `la mère` | the mother |

### The two sounds English speakers must learn

**1. `u` versus `ou`.** These are different sounds, and confusing them changes words.

- `ou` is the easy one: it is English "oo" as in *food*. `nous` — we
- `u` does not exist in English. To make it: say "ee," hold your tongue exactly where it is, then round your lips as if to whistle. `tu` — you

Practice this minimal pair slowly, ten times: `tu` / `tout`, `dessus` / `dessous`, `rue` / `roue`.

If you say `tu` with an "oo" sound, you are saying a different word. This pair is worth real practice time.

**2. `eu`.** Say "ay" as in `é`, then round your lips without moving your tongue.

- `deux` — two
- `je peux` — I can

### Vowel combinations

| Spelling | Sound | Example | English |
|---|---|---|---|
| `ou` | oo | `bonjour` | hello |
| `au`, `eau` | oh | `l'eau` | the water |
| `oi` | wah | `moi` | me |
| `ai`, `ei` | eh | `français` | French |
| `eu`, `œu` | uh (rounded) | `deux` | two |
| `ille` | ee-yuh | `la famille` | the family |

### Retrieval check

Say each pair aloud and state which word has the "oo" sound:

1. `tu` / `tout`
2. `sur` / `sourd`
3. `vu` / `vous`

:::answer
1. `tu` / `tout` — the **oo** sound is in `tout`. `tu` uses the rounded-lip French **u**.
2. `sur` / `sourd` — the **oo** sound is in `sourd`. `sur` uses **u**.
3. `vu` / `vous` — the **oo** sound is in `vous`. `vu` uses **u**.

For the recording task, answers vary. A good recording makes `tu` and `où` clearly different: `tu` starts from an **ee** tongue position with rounded lips, while `où` is the easier **oo** sound.
:::

### Production task

Record yourself saying `Salut, tu vas où ?` — Hi, where are you going? Listen back and check that `tu` and `où` sound clearly different.

### Sentence usage practice

1. `Bonjour, vous allez bien ?` — Hello, are you well?
2. `Tu as deux frères ?` — Do you have two brothers?
3. `Je voudrais de l'eau, s'il vous plaît.` — I would like some water, please.
4. `Moi, j'habite dans une petite rue.` — Me, I live on a small street.
5. `La famille française arrive aujourd'hui.` — The French family arrives today.

:::answer
Model memory check:

1. `Bonjour, vous allez bien ?` — the **ou** sound in `bonjour` and `vous` is the easy **oo** sound, not the French **u** of `tu`.
2. `Tu as deux frères ?` — `tu` uses the rounded-lip French **u**. `deux` uses the rounded **eu** sound.
3. `Je voudrais de l'eau, s'il vous plaît.` — `de l'eau` is required because `eau` begins with a vowel sound. `s'il vous plaît` is the polite fixed phrase here.
4. `Moi, j'habite dans une petite rue.` — `je` becomes `j'` before the silent **h** of `habite`. `rue` contains French **u**, not **ou**.
5. `La famille française arrive aujourd'hui.` — `française` needs the cedilla and the final silent **e**. `aujourd'hui` keeps its apostrophe.
:::


## Unit 4: Nasal Vowels

### Core idea

French has vowels pronounced partly **through the nose**. They appear when a vowel is followed by `n` or `m` **and no vowel comes after that `n`/`m`**.

The key point: in a nasal vowel, **you do not pronounce the `n` or `m` as a consonant**. The letter is an instruction to send the vowel through your nose, then it disappears.

### The four nasal vowels

| Spelling | Rough sound | Example | English |
|---|---|---|---|
| `an`, `am`, `en`, `em` | "ahn" | `grand`, `le temps` | big, time/weather |
| `on`, `om` | "ohn" | `bon`, `le nom` | good, the name |
| `in`, `im`, `ain`, `ein`, `yn` | "anh" | `le vin`, `le pain` | wine, bread |
| `un`, `um` | "uhn" | `un`, `le parfum` | a/one, perfume |

Many speakers today merge `un` into `in`. As a beginner you may safely do the same; you will still be understood.

### When the vowel is NOT nasal

If a vowel follows the `n`/`m`, or the `n`/`m` is doubled, the sound is normal and you pronounce the consonant:

| Nasal | Not nasal | Why |
|---|---|---|
| `un` — a/one | `une` — a/one (fem.) | A vowel follows the n. |
| `bon` — good | `bonne` — good (fem.) | The n is doubled. |
| `américain` | `américaine` | A silent `-e` follows, so the n is pronounced. |

This is the pronunciation half of gender agreement. `bon`/`bonne` and `américain`/`américaine` sound clearly different, and that difference is one of the most audible signals of gender in speech.

### Retrieval check

Nasal or not nasal?

1. `important`
2. `téléphone`
3. `italien`
4. `italienne`
5. `combien`

:::answer
1. `important` — nasal. The ending has a vowel followed by **n** with no vowel pronounced after it.
2. `téléphone` — not nasal. A vowel follows the **n**, so the **n** is pronounced normally.
3. `italien` — nasal. The ending **ien** is nasal here.
4. `italienne` — not nasal. The doubled **n** is pronounced, so the vowel is no longer nasal.
5. `combien` — nasal. Both parts of the word contain nasal vowel spellings.

For the production pairs, answers vary. The rule to listen for is that the feminine form often stops the nasal vowel: `bon` is nasal, but `bonne` pronounces the **n**.
:::

### Production task

Say each masculine/feminine pair aloud five times: `un`/`une`, `bon`/`bonne`, `canadien`/`canadienne`.

### Sentence usage practice

1. `Un grand pain, s'il vous plaît.` — One large loaf of bread, please.
2. `Bonjour, comment vous appelez-vous ?` — Hello, what is your name?
3. `Il est canadien et elle est canadienne.` — He is Canadian and she is Canadian.
4. `Combien de temps ?` — How much time?
5. `C'est un bon restaurant italien.` — It is a good Italian restaurant.

:::answer
Model memory check:

1. `Un grand pain, s'il vous plaît.` — `un`, `grand`, and `pain` all contain nasal vowels. In `grand`, the final **d** is silent.
2. `Bonjour, comment vous appelez-vous ?` — `comment` has a nasal vowel and a silent final **t**. The formal question repeats `vous` after the verb.
3. `Il est canadien et elle est canadienne.` — `canadien` is nasal at the end; `canadienne` is not nasal because the **n** is doubled and pronounced.
4. `Combien de temps ?` — `combien` contains two nasal vowel spellings. `temps` has a nasal vowel and silent final letters.
5. `C'est un bon restaurant italien.` — `bon` is nasal, and `restaurant` has a nasal ending. `italien` is nasal because nothing follows the **n**.
:::


## Unit 5: Consonants That Behave Differently

### The French `r`

The French `r` is made **in the back of the throat**, not with the tip of the tongue. Start from the sound at the end of the Scottish *loch* or a soft gargle, then soften it.

- `bonjour` — hello
- `merci` — thank you
- `Paris` — Paris

An English `r` will be understood. Aim for improvement over time rather than perfection now.

### Soft and hard `c` and `g`

Before `e`, `i`, `y`, both letters go "soft." Elsewhere they are "hard."

| Letter | Before `e`, `i`, `y` | Elsewhere |
|---|---|---|
| `c` | "s": `le cinéma` | "k": `le café` |
| `g` | "zh": `la girafe` | "g" as in *go*: `le gâteau` |

The cedilla `ç` forces the soft sound where it would otherwise be hard: `français` — French.

### Other key consonants

| Spelling | Sound | Example | English |
|---|---|---|---|
| `ch` | "sh" | `le chat` | the cat |
| `j` | "zh" | `je` | I |
| `qu` | "k" only | `qui` | who |
| `gn` | "ny" as in *canyon* | `la montagne` | the mountain |
| `th` | plain "t" | `le thé` | the tea |
| `s` between two vowels | "z" | `la maison` | the house |
| `ss` | "s" | `le poisson` | the fish |

That last pair matters: `le poisson` is the fish, `le poison` is poison. One `s` between vowels sounds like "z."

### Retrieval check

Say each word aloud, then state the sound of the highlighted letter:

1. `ça`
2. `le garçon`
3. `la chaise`
4. `qui`
5. `la cuisine`

:::answer
1. `ça` — the **ç** sounds like **s**. The cédille keeps **c** soft before **a**.
2. `le garçon` — the **ç** again sounds like **s**, this time before **o**.
3. `la chaise` — **ch** sounds like **sh**.
4. `qui` — **qu** sounds like **k** only; the **u** is not a separate vowel.
5. `la cuisine` — the **c** sounds like **k** because it comes before **u**, not before **e**, **i**, or **y**.

The habit to build is to look at the next letter. With **c** and **g**, the following vowel often tells you whether the sound is hard or soft.
:::

### Sentence usage practice

1. `Merci beaucoup !` — Thank you very much!
2. `Le garçon mange du poisson.` — The boy is eating fish.
3. `Je voudrais un thé, s'il vous plaît.` — I would like a tea, please.
4. `Qui est-ce ?` — Who is it?
5. `La cuisine de la maison est grande.` — The kitchen of the house is large.

:::answer
Model memory check:

1. `Merci beaucoup !` — the final **p** of `beaucoup` is silent. French leaves a space before the exclamation mark.
2. `Le garçon mange du poisson.` — the cedilla in `garçon` keeps **c** soft before **o**. In `poisson`, the doubled **ss** gives an **s** sound.
3. `Je voudrais un thé, s'il vous plaît.` — **th** is pronounced like a plain **t** in French. `s'il vous plaît` keeps its apostrophe and accent.
4. `Qui est-ce ?` — `qu` makes only a **k** sound; the **u** is not pronounced separately. French spacing before the question mark still applies.
5. `La cuisine de la maison est grande.` — the **s** between vowels in `maison` sounds like **z**. The final **e** in `grande` makes the **d** audible.
:::


## Unit 6: Elision, Liaison, and Rhythm

### Elision: dropping a vowel

When a short word ending in a vowel meets a word starting with a vowel sound, the vowel is dropped and replaced by an apostrophe. This is **required**, not optional.

| Words | Becomes | English |
|---|---|---|
| `le` + `ami` | `l'ami` | the friend |
| `je` + `habite` | `j'habite` | I live |
| `ne` + `est` | `n'est` | is not |
| `de` + `eau` | `d'eau` | of water |
| `que` + `il` | `qu'il` | that he |

Remember that `h` is silent, so a word starting with `h` usually counts as starting with a vowel: `l'hôtel`, `j'habite`.

You will apply elision in every chapter from Chapter 1 onward.

### Liaison: linking words together

Normally a final consonant is silent. But when the next word begins with a vowel sound, that consonant often **wakes up and links** to it.

| Written | Sounds like | English |
|---|---|---|
| `les amis` | "lay-z-ami" | the friends |
| `vous êtes` | "vou-z-et" | you are |
| `un grand arbre` | "un grahn-t-arbre" | a big tree |
| `mon ami` | "mon-n-ami" | my friend |

Sound changes in liaison: `s` and `x` become "z," and `d` becomes "t."

Liaison is often the **only** way to hear that something is plural, because the plural `-s` is otherwise silent:

- `le ami` is impossible, but compare `l'ami` (one friend) with `les amis` (several friends, linked with a "z")

Do not force liaison everywhere. Learn it first in fixed high-frequency phrases such as `vous avez`, `nous avons`, `les enfants`, `c'est un`. One firm rule: **never link after `et`** (and). `un livre et un stylo` has no link after `et`.

### Rhythm and stress

English stresses one syllable hard inside a word. French does not. French gives **roughly equal weight to every syllable**, with a slight lengthening on the **last syllable of a group of words**.

- English: *IM-por-tant*
- French: `important` — three even syllables, with a small push on the last

Try `C'est un restaurant italien.` — It is an Italian restaurant. Say it as one smooth group with no strong internal stress. Sounding French depends more on this even rhythm than on any single consonant.

### Retrieval check

1. Write `je` + `aime` correctly.
2. Write `ne` + `a` + `pas` around the verb.

4. After which small word is liaison forbidden?

:::answer
1. `j'aime` — `je` becomes `j'` before a vowel sound. Elision is written with an apostrophe.
2. `n'a pas` — the full sentence could be `Il n'a pas de café.` `ne` becomes `n'` before the vowel sound in `a`.
3. In `nous avons`, the final **s** of `nous` links as a **z** sound.
4. Liaison is forbidden after `et`. In `un homme et une femme`, do not link from `et` into `une`.

The rule difference: elision changes the spelling, while liaison changes the sound between two written words.
:::

## Unit 7: Greetings, Politeness, and `tu` or `vous`

### Core idea

French politeness is more explicit than English politeness. Adding `bonjour` before a request is not optional decoration; leaving it out sounds abrupt to French ears.

> **The single most useful habit in this course:** begin every interaction with `Bonjour` (or `Bonsoir` in the evening) before you say anything else.

### Essential greetings

| French | English | When to use |
|---|---|---|
| `Bonjour` | Hello / Good morning | Any time until evening. Always safe. |
| `Bonsoir` | Good evening | From roughly 6 p.m. |
| `Salut` | Hi / Bye | Informal only, with friends. |
| `Au revoir` | Goodbye | Any situation. |
| `Bonne journée` | Have a good day | When leaving. |
| `À bientôt` | See you soon | Informal farewell. |

### Please, thank you, sorry

| French | English | Note |
|---|---|---|
| `S'il vous plaît` | Please | Formal or to a group. |
| `S'il te plaît` | Please | Informal, one person you know. |
| `Merci` | Thank you | Universal. |
| `Merci beaucoup` | Thank you very much | Warmer. |
| `De rien` | You're welcome | Literally "of nothing." |
| `Excusez-moi` | Excuse me | To get attention or apologize. |
| `Pardon` | Sorry / Excuse me | Short, for bumping into someone. |

### Choosing `tu` or `vous`

This choice exists in every French sentence you address to someone, so decide it early.

| Use `tu` | Use `vous` |
|---|---|
| a close friend | someone you have just met |
| a family member | a shop assistant, waiter, official |
| a child | someone noticeably older |
| a classmate of similar age | **any group of people**, always |

**When in doubt, use `vous`.** An unnecessary `vous` sounds polite. An unwanted `tu` sounds rude. A French speaker will invite you to switch by saying `On peut se tutoyer ?` — Shall we use "tu" with each other?

Note that `vous` is also the plural "you." Even with close friends, once there are two of them, you must use `vous`.

### Asking how someone is

| French | English | Register |
|---|---|---|
| `Ça va ?` | How's it going? | Informal |
| `Comment ça va ?` | How are you? | Neutral |
| `Comment allez-vous ?` | How are you? | Formal |
| `Ça va bien, merci. Et vous ?` | I'm well, thanks. And you? | Polite reply |
| `Ça va, et toi ?` | I'm fine, and you? | Informal reply |

Always return the question. Answering `Ça va` and stopping sounds like you are ending the conversation.

### Sentence usage practice

1. `Bonjour madame, comment allez-vous ?` — Hello ma'am, how are you?
2. `Salut ! Ça va ?` — Hi! How's it going?
3. `Un café, s'il vous plaît.` — A coffee, please.
4. `Merci beaucoup. — De rien.` — Thank you very much. — You're welcome.
5. `Excusez-moi, où est la gare ?` — Excuse me, where is the train station?
6. `Au revoir, bonne journée !` — Goodbye, have a good day!

:::answer
Model memory check:

1. `Bonjour madame, comment allez-vous ?` — use `vous` with a stranger or in a formal situation.
2. `Salut ! Ça va ?` — `salut` is informal, so it belongs with friends, family, or peers.
3. `Un café, s'il vous plaît.` — the request is polite because it includes `s'il vous plaît`; in real life, say `Bonjour` first.
4. `Merci beaucoup. — De rien.` — this is the normal thank-you and reply pair.
5. `Excusez-moi, où est la gare ?` — `où` needs the accent to mean where, and `excusez-moi` uses the formal or plural form.
6. `Au revoir, bonne journée !` — this is a standard daytime farewell; French leaves a space before `!`.

For any greeting line, mark yourself wrong if the social register is wrong even when the words are grammatical.
:::

### Numbers 0 to 20

Chapter 4 covers the full number system. These twenty are enough to give your age, a price, and a phone number.

| # | French | # | French |
|---:|---|---:|---|
| 0 | `zéro` | 11 | `onze` |
| 1 | `un` | 12 | `douze` |
| 2 | `deux` | 13 | `treize` |
| 3 | `trois` | 14 | `quatorze` |
| 4 | `quatre` | 15 | `quinze` |
| 5 | `cinq` | 16 | `seize` |
| 6 | `six` | 17 | `dix-sept` |
| 7 | `sept` | 18 | `dix-huit` |
| 8 | `huit` | 19 | `dix-neuf` |
| 9 | `neuf` | 20 | `vingt` |

Pronunciation warnings:

- The final consonant of `cinq`, `six`, `huit`, `dix` is pronounced when the number stands alone, but often changes before a noun: `six` alone ends in "s," yet `six livres` drops it and `six ans` links as "z."
- `sept` keeps its "t" but drops the `p`.
- `vingt` has a silent `t` when alone.

Do not over-study this now. Say the numbers in order daily until they are automatic.

### Introducing yourself

These sentences use grammar from Chapters 1-4. Learn them now as **fixed chunks**; the rules behind them arrive later.

| French | English |
|---|---|
| `Je m'appelle Marie.` | My name is Marie. |
| `Comment vous appelez-vous ?` | What is your name? (formal) |
| `Comment tu t'appelles ?` | What is your name? (informal) |
| `Enchanté.` / `Enchantée.` | Nice to meet you. (m. / f.) |
| `J'ai vingt ans.` | I am twenty years old. |

Two things to notice now and understand later:

1. French uses **have**, not **be**, for age: `J'ai vingt ans` literally means "I have twenty years." Chapter 2 explains this.
2. `Enchanté` adds an `-e` if you are female. That is adjective agreement, taught in Chapter 1.

### Survival phrases when you are stuck

These four sentences will keep almost any beginner conversation alive:

- `Je ne comprends pas.` — I don't understand.
- `Pouvez-vous répéter, s'il vous plaît ?` — Can you repeat, please?
- `Plus lentement, s'il vous plaît.` — More slowly, please.
- `Comment dit-on "book" en français ?` — How do you say "book" in French?

A fuller list is in [`survival-phrases.md`](survival-phrases.md).

### Production task

## Common mistakes to avoid

1. **Pronouncing final consonants.** `petit` ends in a silent t. Remember CaReFuL for the usual exceptions.
2. **Saying `tu` with an "oo" sound.** `tu` and `tout` are different words. Practice the rounded-lip `u` separately.
3. **Pronouncing the `n` in a nasal vowel.** In `bon`, the n is an instruction for the vowel, not a consonant you say.
4. **Treating accents as optional.** `ou` (or) and `où` (where) are different words; write the accent.
5. **Forgetting elision.** Write `j'habite`, never `je habite`.
6. **Stressing one syllable hard.** French syllables are even. Uneven stress is the most common reason a learner sounds foreign even with correct sounds.
7. **Starting a request without `bonjour`.** Say `Bonjour` first, every time.
8. **Using `tu` with a stranger.** Default to `vous` until invited to switch.
9. **Assuming `ils parlent` sounds different from `il parle`.** The `-ent` ending is silent; only the subject reveals number.

## Mini-dialogue: arriving at a café

Read the dialogue in French first. Then use the English to check your understanding.

**Serveur :** `Bonjour madame, vous désirez ?` — Hello ma'am, what would you like?

**Claire :** `Bonjour. Un café et un croissant, s'il vous plaît.` — Hello. A coffee and a croissant, please.

**Serveur :** `Très bien. C'est tout ?` — Very good. Is that all?

**Claire :** `Oui, c'est tout. Ça fait combien ?` — Yes, that's all. How much is it?

**Serveur :** `Six euros, s'il vous plaît.` — Six euros, please.

**Claire :** `Pardon, je ne comprends pas. Plus lentement, s'il vous plaît ?` — Sorry, I don't understand. More slowly, please?

**Serveur :** `Six euros.` — Six euros.

**Claire :** `Ah, merci beaucoup ! Au revoir.` — Ah, thank you very much! Goodbye.

**Serveur :** `Au revoir, bonne journée !` — Goodbye, have a good day!

### Guided analysis

1. Find every use of `s'il vous plaît` and explain why the formal form is correct here.
2. Find two silent final consonants in the dialogue.
3. Find one nasal vowel in `bonjour`, `combien`, and `six euros`.
4. Where does liaison occur in `six euros`? What sound links them?
5. Rewrite Claire's first line as if she were speaking to a close friend.

:::answer
1. `s'il vous plaît` appears in `Un café et un croissant, s'il vous plaît.`, `Six euros, s'il vous plaît.`, and `Plus lentement, s'il vous plaît ?` The formal form is correct because Claire and the server are strangers in a service interaction.
2. Two silent final consonants: final **t** in `tout` and final **t** in `lentement`. Another clear one is final **p** in `beaucoup` from `merci beaucoup`. In `six euros`, the final written **x** is not silent because it links to the next word.
3. Nasal vowels: `bonjour` has the nasal **on** in the first syllable. `combien` has two, the **om** of `com-` and the **ien** at the end. `six euros` has none — the useful sound there is liaison, not nasality.
4. In `six euros`, the final **x** links to `euros` with a **z** sound: `six euros`.
5. Close-friend version: `Salut. Un café et un croissant, s'il te plaît.` — `vous` changes to `te` because Claire is now speaking to one familiar person.

One existing prompt is a little misleading: `six euros` is mainly a liaison example, not a nasal-vowel example.
:::

## Chapter reference sheet

### Sound traps at a glance

| Trap | Rule |
|---|---|
| Final consonants | Usually silent, except CaReFuL (`c`, `r`, `f`, `l`). |
| Final `-e` | Silent, but makes the previous consonant heard. |
| `-ent` on a verb | Completely silent. |
| `h` | Always silent. |
| `u` vs `ou` | `u` = rounded "ee"; `ou` = "oo." |
| Vowel + `n`/`m` | Nasal, unless a vowel follows or the n is doubled. |
| `s` between vowels | Sounds like "z." |
| `ch` / `j` / `qu` / `gn` | "sh" / "zh" / "k" / "ny." |

### Politeness at a glance

| Situation | Say |
|---|---|
| Entering anywhere | `Bonjour` |
| Making a request | add `s'il vous plaît` |
| Stranger, older person, any group | `vous` |
| Friend, family, child | `tu` |
| Leaving | `Au revoir, bonne journée` |

### Core habits

- Say every French example aloud; never read only with your eyes.
- Imitate the rhythm of a whole phrase before fixing single sounds.
- Learn greetings and politeness as fixed chunks, not word by word.
- Accept that spelling and sound differ; trust the rules over the letters.
- Return to this chapter whenever a new word resists pronunciation.
