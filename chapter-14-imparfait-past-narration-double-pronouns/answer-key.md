## Sections C-F

These are productive tasks. Check them using this rule summary:

- **Forming the imparfait:** Take the present nous form, remove -ons, and add -ais, -ais, -ait, -ions, -iez, -aient. Être uses ét-.
- **Choosing the past tense:** Use the imparfait for background, description, habit, and ongoing action; use the passé composé for bounded completed events.
- **Past narration:** Set the scene with the imparfait and move events forward with the passé composé.
- **Double object pronouns:** Pronoun order is fixed before ordinary verbs. With affirmative commands, pronouns follow the verb in a different order.

## Self-scoring

Award one point for each Section A answer and two points for each structurally correct Section B sentence.

- **85-100%:** proceed and schedule delayed review.
- **70-84%:** review only missed rules and retry the next day.
- **Below 70%:** repeat the lesson in two smaller sessions.

A corrected answer is not mastered until you can produce a different correct example on a later day.
