# Chapter 14 Exercises

Complete these without notes. Put a question mark beside uncertain answers.

## A. Transform or translate

1. nous parlons -> imparfait, je
2. nous finissons -> imparfait, ils
3. It was raining.
4. I was reading when he arrived.
5. Je donne le livre à Paul.
6. Give it to me!

:::answer
1. `je parlais` — Start from `nous parlons`, remove -ons, add -ais.
2. `ils finissaient` — Start from `nous finissons`, so the stem is finiss-, then add -aient.
3. `Il pleuvait.` — Weather/background description normally uses the imparfait.
4. `Je lisais quand il est arrivé.` — `lisais` is the ongoing action; `est arrivé` is the completed interruption.
5. `Je le lui donne.` — `le` is the direct object and comes before indirect `lui`.
6. `Donnez-le-moi !` — In an affirmative command, pronouns follow the verb; `me` becomes `moi`.
:::

## B. Controlled production

1. Write a new sentence demonstrating **forming the imparfait**. Use `je parlais` only as a structural model; change its content.
2. Write a new sentence demonstrating **choosing the past tense**. Use `Il pleuvait.` only as a structural model; change its content.
3. Write a new sentence demonstrating **past narration**. Use `Je dormais quand Marie a appelé.` only as a structural model; change its content.
4. Write a new sentence demonstrating **double object pronouns**. Use `Je le lui donne.` only as a structural model; change its content.

:::answer
Answers vary. A correct answer must clearly show the named structure and change the model sentence's content.

1. **Forming the imparfait:** `Nous vendions des livres.` — from `nous vendons`, stem vend-, ending -ions.
2. **Choosing the past tense:** `La salle était calme.` — description/background takes the imparfait.
3. **Past narration:** `Je marchais quand la pluie a commencé.` — ongoing scene in the imparfait, new event in the passé composé.
4. **Double object pronouns:** `Nous les lui envoyons.` — direct `les` comes before indirect `lui`.

Mark yourself wrong if you used a conditional form such as `je parlerais` for the imparfait, or if you reversed `le / la / les` and `lui / leur`.
:::

## C. Four-way variation

Choose one sentence from each lesson unit and rewrite it four ways:

1. change the subject;
2. make it negative;
3. turn it into a question;
4. change one meaningful detail.

:::answer
Answers vary. Worked example from `Je lisais quand le téléphone a sonné.`

1. Change the subject: `Nous lisions quand le téléphone a sonné.` — `lisais` changes to `lisions` for `nous`.
2. Make it negative: `Je ne lisais pas quand le téléphone a sonné.` — the negative wraps the imparfait verb.
3. Turn it into a question: `Est-ce que tu lisais quand le téléphone a sonné ?` — the past-tense contrast stays the same.
4. Change one meaningful detail: `Je lisais quand Marie est entrée.` — the interruption is now a different passé composé event.

For your own sentence, ask: which part is background or ongoing, and which part is the completed event?
:::

## D. Dictation and correction

Use text-to-speech to hear six examples from `lessons.md`. Write what you hear without looking. Correct in separate passes:

1. vocabulary;
2. verb form;
3. agreement or pronoun placement;
4. spelling and accents.

Do the dictation first, using this chapter's own examples as your audio. Then open the answers to check: they list six sentences worth dictating and the trap each one sets.

:::answer
Six sentences from this chapter that make good dictation material, and the trap each one sets:

1. `Il pleuvait et les rues étaient presque vides.` — Both verbs are imparfait; the silent endings make subject agreement easy to miss.
2. `Je lisais dans ma chambre quand le téléphone a sonné.` — The contrast is the trap: ongoing `lisais`, sudden event `a sonné`.
3. `Nous habitions à Paris lorsque nous avons rencontré Léa.` — `habitions` and `avons` both include the `nous` sound, but they belong to different tenses.
4. `Paul voulait les billets, alors je les lui ai donnés.` — The cluster `les lui` must stay in that order, and `donnés` agrees with `les billets`.
5. `La serveuse nous apportait toujours du thé.` — `nous` is unstressed and easy to drop; it is the indirect recipient.
6. `Prends-les-moi tout de suite et mets-les-y !` — Positive commands put pronouns after the verb with hyphens.

Listen once for the whole sentence, then again for the verb endings and pronoun clusters. Correct tense choice before you correct accents.
:::

Write a short travel memory: four background sentences in the imparfait and four completed events in the passé composé.

## F. Oral recall

Explain each of the chapter's four main rules aloud in simple English, then give one French example from memory.

:::answer
1. **Forming the imparfait.** Use the present `nous` form, remove -ons, and add imparfait endings. Example: `nous finissions`.
2. **Choosing the past tense.** Use the imparfait for background, habits, description, and ongoing states; use the passé composé for completed events. Example: `Il pleuvait quand je suis sorti.`
3. **Past narration.** A common story pattern is scene in the imparfait, event in the passé composé. Example: `Je dormais quand elle a appelé.`
4. **Double object pronouns.** Before a verb, the fixed order puts `le`, `la`, `les` before `lui`, `leur`. Example: `Je le lui donne.` In affirmative commands, the pronouns follow: `Donne-le-moi !`
:::
