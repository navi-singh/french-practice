# Handwriting and Active-Recall Drills

Use paper if possible. Do not copy while looking. Study the model, cover it, write it from memory, then compare.

## Drill 1: Article + noun chunks

Write each chunk three times. On the third repetition, cover the model.

1. `le quartier`
2. `la cuisine`
3. `l'appartement` (`m.`)
4. `l'université` (`f.`)
5. `les fenêtres`
6. `un voisin`
7. `une voisine`
8. `des étudiants`

Then write the English meaning beside each phrase without using a dictionary.

## Drill 2: Four-corner agreement

For each adjective, build all four forms.

### Model

`petit`

1. `un petit jardin`
2. `une petite chambre`
3. `des petits jardins`
4. `des petites chambres`

### Your turn

Use these adjectives:

1. `grand`
2. `sportif`
3. `heureux`
4. `canadien`

Choose your own masculine and feminine nouns.

## Drill 3: Singular-to-plural transformations

Write the singular phrase, cover it, and produce the plural:

1. `une chaise rouge`
2. `un nouvel étudiant`
3. `le beau tableau`
4. `la petite rue`
5. `un animal actif`

## Drill 4: Dictation

Have your computer or pronunciation extension read these aloud. Do not look while writing:

1. `une grande maison blanche`
2. `des étudiants français`
3. `un vieux quartier tranquille`
4. `les nouvelles voitures rouges`
5. `une amie canadienne`

Check articles, accents, adjective position, gender, and plural endings separately.

## Drill 5: Memory sentences

Study each sentence for fifteen seconds. Hide it and write it from memory:

1. `La petite bibliothèque est dans une rue tranquille.`
2. `Les nouveaux étudiants ont des cahiers bleus.`
3. `Une voisine française habite dans le vieil immeuble.`

Circle every article. Underline every noun. Draw an arrow from each adjective to its noun.

## Drill 6: Personal production

Write six original sentences:

1. Describe one room.
2. Describe one person.
3. Describe two objects.
4. Use a color.
5. Use a nationality.
6. Use one adjective before the noun and another after it.

Read the sentences aloud and correct them before adding new vocabulary.
