# Chapter 13 Exercises

Complete these without notes. Put a question mark beside uncertain answers.

## A. Transform or translate

1. Je parle.
2. Nous finissons.
3. Elle arrive.
4. Ils se lèvent.
5. I did not see it.
6. The letters? I wrote them.

:::answer
1. `J'ai parlé.` — `parler` is a regular -er verb, so the participle is `parlé`, and the auxiliary is **avoir**.
2. `Nous avons fini.` — `finir` forms the regular participle `fini`, with `avons` for `nous`.
3. `Elle est arrivée.` — `arriver` is an **être** verb, and `arrivée` agrees with feminine singular `elle`.
4. `Ils se sont levés.` — Pronominal verbs use **être**; `levés` agrees with masculine or mixed plural `ils`.
5. `Je ne l'ai pas vu.` — The negative surrounds the auxiliary, and `l'` before `ai` is treated as masculine singular here, so `vu` has no visible agreement.
6. `Les lettres ? Je les ai écrites.` — `les` is a preceding direct object pronoun referring to feminine plural `les lettres`, so `écrit` becomes `écrites`.
:::

## B. Controlled production

1. Write a new sentence demonstrating **avoir + past participle**. Use `J'ai parlé.` only as a structural model; change its content.
2. Write a new sentence demonstrating **irregular participles**. Use `Il a fait du sport.` only as a structural model; change its content.
3. Write a new sentence demonstrating **être verbs**. Use `Elle est arrivée.` only as a structural model; change its content.
4. Write a new sentence demonstrating **placement and agreement**. Use `Je n'ai pas mangé.` only as a structural model; change its content.

:::answer
Answers vary. A correct answer must show the named structure and change the model sentence's content.

1. **Avoir + past participle:** `Nous avons vendu la voiture.` — **avoir** plus regular participle `vendu`; no agreement because the object follows.
2. **Irregular participle:** `Elle a pris le métro.` — `prendre` has the irregular participle `pris`.
3. **Être verbs:** `Mes amies sont parties tôt.` — **être** verb with subject agreement: feminine plural `parties`.
4. **Placement and agreement:** `Les photos ? Je les ai prises.` — the preceding direct object `les` refers to feminine plural `photos`, so the participle agrees.

Mark yourself wrong if you used an infinitive after the auxiliary, chose **avoir** for an **être** verb, or missed required agreement.
:::

## C. Four-way variation

Choose one sentence from each lesson unit and rewrite it four ways:

1. change the subject;
2. make it negative;
3. turn it into a question;
4. change one meaningful detail.

:::answer
Answers vary. Worked example from `Elle est arrivée à huit heures.`

1. Change the subject: `Ils sont arrivés à huit heures.` — **être** stays the auxiliary, and `arrivés` agrees with `ils`.
2. Make it negative: `Elle n'est pas arrivée à huit heures.` — `ne...pas` surrounds the auxiliary `est`.
3. Turn it into a question: `Est-ce qu'elle est arrivée à huit heures ?` — the auxiliary remains after the subject in the `est-ce que` form.
4. Change one meaningful detail: `Elle est arrivée à midi.` — tense and agreement stay the same; only the time changes.

For your own choices, check auxiliary choice first, then pronoun placement, then agreement.
:::

## D. Dictation and correction

Use text-to-speech to hear six examples from `lessons.md`. Write what you hear without looking. Correct in separate passes:

1. vocabulary;
2. verb form;
3. agreement or pronoun placement;
4. spelling and accents.

Do the dictation first, using this chapter's own examples as your audio. Then open the answers to check: they list six sentences worth dictating and the trap each one sets.

:::answer
Six sentences from this chapter that make good dictation material, and the trap each one sets:

1. `J'ai terminé mes devoirs.` — The trap is the accent in `terminé`; the second verb is a past participle, not an infinitive.
2. `Nous avons écrit à notre professeur.` — `écrit` ends with a silent consonant, and `à` has an accent.
3. `Je n'ai pas mangé.` — The negative surrounds `ai`; do not write `Je n'ai mangé pas`.
4. `Marie est arrivée à huit heures.` — `arrivée` has feminine agreement with `Marie`, and `à` appears before the time.
5. `Elle s'est lavé les mains.` — There is no agreement on `lavé` because `les mains` is the direct object and comes after the verb.
6. `Les photos ? Je les ai prises pendant le voyage.` — `prises` agrees with the preceding direct object `les`, referring to feminine plural `photos`.

Correct in passes: first recover the words, then the auxiliary, then agreement, then accents and apostrophes.
:::

## F. Oral recall

Explain each of the chapter's four main rules aloud in simple English, then give one French example from memory.

:::answer
1. **Avoir + past participle.** Most verbs use present-tense **avoir** plus a past participle. Example: `J'ai fini le travail.`
2. **Irregular participles.** Common verbs must be memorized: `fait`, `pris`, `vu`, `lu`, `écrit`. Example: `Elle a pris le bus.`
3. **Être verbs.** Movement/change verbs and pronominal verbs use **être**, and the participle usually agrees with the subject. Example: `Ils sont partis tôt.`
4. **Placement and agreement.** Negation surrounds the auxiliary, and a preceding direct object pronoun can trigger agreement. Example: `Les clés ? Je les ai prises.`

If you can explain the rule but cannot create a new French example, review the unit before moving on.
:::
