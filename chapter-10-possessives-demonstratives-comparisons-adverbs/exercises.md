# Chapter 10 Exercises

Complete these without notes. Put a question mark beside uncertain answers.

## A. Transform or translate

1. my female friend
2. this tree
3. those houses
4. Marie is taller than Luc.
5. We have as much time.
6. heureuse -> adverb

## B. Controlled production

1. Write a new sentence demonstrating **possessives**. Use `mon frère` only as a structural model; change its content.
2. Write a new sentence demonstrating **demonstratives**. Use `ce livre` only as a structural model; change its content.
3. Write a new sentence demonstrating **comparisons**. Use `Elle est plus rapide que moi.` only as a structural model; change its content.
4. Write a new sentence demonstrating **adverbs**. Use `lentement` only as a structural model; change its content.

## C. Four-way variation

Choose one sentence from each lesson unit and rewrite it four ways:

1. change the subject;
2. make it negative;
3. turn it into a question;
4. change one meaningful detail.

## D. Dictation and correction

Use text-to-speech to hear six examples from `lessons.md`. Write what you hear without looking. Correct in separate passes:

1. vocabulary;
2. verb form;
3. agreement or pronoun placement;
4. spelling and accents.

## E. Personal writing

Compare two family members or two cities in eight sentences using possessives, demonstratives, and three comparison patterns.

## F. Oral recall

Explain each of the chapter's four main rules aloud in simple English, then give one French example from memory.
