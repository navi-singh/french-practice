# Chapter 16 Exercises

Complete these without notes. Put a question mark beside uncertain answers.

## A. Transform or translate

1. parler, que je
2. finir, que nous
3. être, qu'il
4. Il faut / vous venir
5. Je veux / tu réussir
6. I am happy that she is here.

## B. Controlled production

1. Write a new sentence demonstrating **forming the subjunctive**. Use `que je parle` only as a structural model; change its content.
2. Write a new sentence demonstrating **important irregulars**. Use `que je sois` only as a structural model; change its content.
3. Write a new sentence demonstrating **necessity and judgment**. Use `Il faut que vous veniez.` only as a structural model; change its content.
4. Write a new sentence demonstrating **volition, emotion, and doubt**. Use `Je veux que tu réussisses.` only as a structural model; change its content.

## C. Four-way variation

Choose one sentence from each lesson unit and rewrite it four ways:

1. change the subject;
2. make it negative;
3. turn it into a question;
4. change one meaningful detail.

## D. Dictation and correction

Use text-to-speech to hear six examples from `lessons.md`. Write what you hear without looking. Correct in separate passes:

1. vocabulary;
2. verb form;
3. agreement or pronoun placement;
4. spelling and accents.

## E. Personal writing

Write eight recommendations for a friend using il faut que, je veux que, il est important que, and je suis content que.

## F. Oral recall

Explain each of the chapter's four main rules aloud in simple English, then give one French example from memory.
