# Chapter 4 Exercises

Complete these without notes. Put a question mark beside uncertain answers.

## A. Transform or translate

1. 42
2. 1 May
3. 14:30
4. nous / finir
5. elles / choisir
6. vous / réussir

:::answer
1. `quarante-deux` — compound numbers usually use hyphens.
2. `le premier mai` — dates use `premier` only for the first day of the month.
3. `Il est quatorze heures trente.` — clock time uses fixed `Il est`; 14:30 is common 24-hour schedule style.
4. `nous finissons` — regular -ir verbs use the **-issons** form with `nous`.
5. `elles choisissent` — `elles` takes the **-issent** ending; the ending is written and the **iss** sound is heard.
6. `vous réussissez` — `vous` takes the **-issez** ending.

These match the answer key exactly. The common traps are hyphens in numbers, `premier` only on the first, and the plural **-iss-** forms of regular -ir verbs.
:::


## B. Controlled production

1. Write a new sentence demonstrating **numbers and dates**. Use `le premier mai` only as a structural model; change its content.
2. Write a new sentence demonstrating **time**. Use `Il est huit heures.` only as a structural model; change its content.
3. Write a new sentence demonstrating **regular -ir verbs**. Use `Je finis tôt.` only as a structural model; change its content.
4. Write a new sentence demonstrating **functional practice**. Use `Le magasin ouvre à neuf heures.` only as a structural model; change its content.

:::answer
Answers vary by design. A correct answer must clearly show the named structure and preserve number spelling, time wording, verb endings, and word order.

Sample answers:

1. Numbers and dates: `le deux juin` — for dates after the first, French uses a cardinal number, not an ordinal.
2. Time: `Il est dix heures trente.` — basic clock time uses the fixed expression `Il est`.
3. Regular -ir verbs: `Nous choisissons un dessert.` — `nous` requires the **-issons** form.
4. Functional practice: `Le train arrive à dix-neuf heures.` — `à` introduces the scheduled time.

Mark yourself wrong if you reused the model content, wrote a digit when the task expects French words, used `C'est` for clock time, or forgot the **-iss-** in a plural regular -ir form.
:::


## C. Four-way variation

Choose one sentence from each lesson unit and rewrite it four ways:

1. change the subject;
2. make it negative;
3. turn it into a question;
4. change one meaningful detail.

:::answer
Worked example, starting from `Nous choisissons deux desserts à midi.`

1. Change the subject: `Je choisis deux desserts à midi.` — `choisissons` changes to `choisis` because the subject is now `je`.
2. Make it negative: `Nous ne choisissons pas deux desserts à midi.` — `ne` and `pas` wrap the conjugated verb.
3. Turn it into a question: `Est-ce que nous choisissons deux desserts à midi ?` — this keeps statement word order after `est-ce que`.
4. Change one meaningful detail: `Nous choisissons trois cafés à dix heures.` — the number, object, and time changed, but the `nous` verb form stayed the same.

Check that changing a number or time did not distract you from the verb ending. The subject still controls the verb.
:::


## D. Dictation and correction

Use text-to-speech to hear six examples from `lessons.md`. Write what you hear without looking. Correct in separate passes:

1. vocabulary;
2. verb form;
3. agreement or pronoun placement;
4. spelling and accents.

Do the dictation first, using this chapter's own examples as your audio. Then open the answers to check: they list six sentences worth dictating and the trap each one sets.

:::answer
Six sentences from this chapter that make good dictation material, and the trap each one sets:

1. `Le café coûte cinq euros.` — `cinq` may sound different depending on what follows, but the written number stays the same.
2. `Le voyage coûte quatre-vingt-dix euros.` — ninety is built as `quatre-vingt-dix`; keep the hyphens and do not add an **s** to `vingt` when another number follows.
3. `Mon anniversaire est le premier novembre.` — dates use `premier` only for the first day of the month, and months stay lowercase.
4. `Il est dix-neuf heures trente.` — 24-hour clock time uses `heures`; `dix-neuf` keeps its hyphen.
5. `Nous choisissons deux desserts pour huit euros.` — the regular -ir plural form has the audible **-issons**.
6. `En deux mille vingt-six, je réussis enfin mon objectif.` — `mille` never takes **s**, and `réussis` has the accent on `é`.

Correct in passes. A missed number hyphen, a wrong verb ending, and a missing accent are different errors, so do not count them as the same problem.
:::

## E. Personal writing

Write a one-day schedule with five times, three prices, and four regular -ir verb forms.

:::answer
Answers vary. A model one-day schedule:

1. `À huit heures, je choisis un café pour trois euros.`
2. `À neuf heures quinze, je finis un exercice.`
3. `À midi, nous choisissons deux sandwichs pour douze euros.`
4. `À dix-sept heures, vous réussissez la réservation.`
5. `À vingt heures, ils finissent le dîner pour vingt euros.`

Self-marking criteria:

- Include five time expressions.
- Include three prices.
- Include four regular -ir verb forms, with correct endings for their subjects.
- Spell number words correctly and use hyphens in compound numbers such as `dix-sept` or `vingt-deux`.
- Use `à` before times when saying when something happens.
:::


## F. Oral recall

Explain each of the chapter's four main rules aloud in simple English, then give one French example from memory.

:::answer
1. **Numbers and dates.** Use the French number patterns, including hyphens in compound numbers. Dates use cardinal numbers except `le premier`. Example: `le premier mai`.
2. **Time.** Use `Il est...` for clock time, with `midi` and `minuit` as special forms. Example: `Il est quatorze heures trente.`
3. **Regular -ir verbs.** For verbs like `finir`, remove **-ir** and add **-is**, **-is**, **-it**, **-issons**, **-issez**, **-issent**. Example: `Nous finissons tôt.`
4. **Functional practice.** Combine quantities, prices, times, and verbs in real situations. Example: `Je choisis deux cafés pour huit euros.`

If your explanation is correct but your French example has a wrong ending or missing hyphen, count the item as not mastered yet.
:::
