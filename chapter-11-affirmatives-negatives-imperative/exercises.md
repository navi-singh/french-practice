# Chapter 11 Exercises

Complete these without notes. Put a question mark beside uncertain answers.

## A. Transform or translate

1. You never speak.
2. with her
3. You (tu) listen.
4. We finish.
5. Look at it.
6. Do not give it to him.

:::answer
These answers match the answer key.

1. `Vous ne parlez jamais.` — `jamais` replaces `pas` and means never. The answer key chooses polite or plural `vous` for **you**.
2. `avec elle` — after a preposition, use the stressed pronoun `elle`, not a subject form.
3. `Écoute !` — a `tu` command for a regular -er verb drops the final letter found in the present-tense spelling and has no subject pronoun.
4. `Finissons !` — the `nous` command uses the `nous` verb form without the subject pronoun.
5. `Regarde-le !` — in an affirmative command, the object pronoun follows the verb with a hyphen.
6. `Ne le lui donne pas !` — in a negative command, pronouns go before the verb; direct `le` comes before indirect `lui`, and `pas` follows the verb.
:::

## B. Controlled production

1. Write a new sentence demonstrating **expanded negatives**. Use `Je ne vois personne.` only as a structural model; change its content.
2. Write a new sentence demonstrating **stressed pronouns**. Use `avec moi` only as a structural model; change its content.
3. Write a new sentence demonstrating **imperative forms**. Use `Parle !` only as a structural model; change its content.
4. Write a new sentence demonstrating **commands with pronouns**. Use `Regarde-le !` only as a structural model; change its content.

:::answer
Answers vary. A correct sentence must clearly show the named structure and place command pronouns correctly.

Sample answers:

1. Expanded negatives: `Je ne vois rien dans le sac.` — `rien` replaces `pas` and comes after the verb here.
2. Stressed pronouns: `Je travaille avec eux.` — after `avec`, use the stressed form.
3. Imperative forms: `Fermez la porte !` — command form with no subject pronoun.
4. Commands with pronouns: `Donne-le-moi !` — affirmative command pronouns come after the verb with hyphens.

Mark yourself wrong if you answer a negative question with `oui` when `si` is needed, if a command includes a subject pronoun, or if a negative command leaves the pronoun after the verb.
:::

## C. Four-way variation

Choose one sentence from each lesson unit and rewrite it four ways:

1. change the subject;
2. make it negative;
3. turn it into a question;
4. change one meaningful detail.

:::answer
Worked example, starting from `Donne-moi le livre.`

1. Change the subject: `Donnez-moi le livre.` — switch to the `vous` command form.
2. Make it negative: `Ne me donne pas le livre.` — in a negative command, `me` returns before the verb.
3. Turn it into a question: `Est-ce que tu me donnes le livre ?` — this is no longer a command, so normal pronoun order returns.
4. Change one meaningful detail: `Donne-moi le cahier.`

Check command type first. Affirmative commands put pronouns after the verb; negative commands put them before the verb.
:::

## D. Dictation and correction

Use text-to-speech to hear six examples from `lessons.md`. Write what you hear without looking. Correct in separate passes:

1. vocabulary;
2. verb form;
3. agreement or pronoun placement;
4. spelling and accents.

Do the dictation first, using this chapter's own examples as your audio. Then open the answers to check: they list six sentences worth dictating and the trap each one sets.

:::answer
Six sentences from this chapter that make good dictation material, and the trap each one sets:

1. `Tu n'aimes pas ça ? — Si, j'aime ça.` — the answer is `si` because the question is negative.
2. `Moi, je ne vois personne dans le jardin.` — `Moi` is a stressed pronoun, and the negative frame is **ne ... personne**.
3. `Le professeur parle avec nous après le cours.` — after `avec`, `nous` is the stressed pronoun form.
4. `Parle plus lentement.` — the regular -er `tu` command drops the final written `s`.
5. `Ne laissez rien sur la table !` — negative command with **ne ... rien**; keep the space before `!`.
6. `Donne-moi le marteau et apporte-le-lui ensuite.` — affirmative command pronouns come after the verb with hyphens, and `le` comes before `lui`.

Correct once for vocabulary, once for command forms, once for pronoun placement, and once for accents and punctuation. Do not fix everything in one pass.
:::

## F. Oral recall

Explain each of the chapter's four main rules aloud in simple English, then give one French example from memory.

:::answer
1. **Expanded negatives.** French has negative pairs such as **ne ... jamais**, **ne ... rien**, **ne ... personne**, and **ne ... plus**. Example: `Je ne vois personne.`
2. **Stressed pronouns.** Use `moi`, `toi`, `lui`, `elle`, `nous`, `vous`, `eux`, and `elles` after prepositions, for emphasis, in comparisons, and in short answers. Example: `Je viens avec eux.`
3. **Imperative forms.** Commands use `tu`, `nous`, or `vous` verb forms without subject pronouns. Example: `Écoutez !`
4. **Commands with pronouns.** Affirmative command pronouns follow the verb; negative command pronouns come before it. Example: `Regarde-le !` / `Ne le regarde pas !`

If you can recite the rule but put the pronoun on the wrong side of the verb, redo the command section. Placement is the point of the chapter.
:::
