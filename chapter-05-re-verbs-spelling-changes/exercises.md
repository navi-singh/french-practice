# Chapter 5 Exercises

Complete these without notes. Put a question mark beside uncertain answers.

## A. Transform or translate

1. nous / attendre
2. il / répondre
3. nous / commencer
4. nous / manger
5. elle / acheter
6. J'habite ici. I started three years ago.

:::answer
1. `nous attendons` — Regular -re verb: remove -re from `attendre`, then add -ons for `nous`.
2. `il répond` — The `il / elle / on` form has no extra ending after the stem; do not write `réponds` here.
3. `nous commençons` — `commencer` needs ç in the `nous` form to keep the soft sound.
4. `nous mangeons` — `manger` adds e before -ons so the g stays soft.
5. `elle achète` — `acheter` changes e to è in the `elle` form.
6. `J'habite ici depuis trois ans.` — French uses present tense with `depuis` because the living situation began three years ago and still continues.
:::


## B. Controlled production

1. Write a new sentence demonstrating **regular -re verbs**. Use `J'attends le bus.` only as a structural model; change its content.
2. Write a new sentence demonstrating **depuis**. Use `J'habite ici depuis deux ans.` only as a structural model; change its content.
3. Write a new sentence demonstrating **spelling changes**. Use `Nous commençons.` only as a structural model; change its content.
4. Write a new sentence demonstrating **shopping language**. Use `Je préfère la chemise bleue.` only as a structural model; change its content.

:::answer
Answers vary. A correct sentence must demonstrate the named structure, use the right verb form, and not simply copy the model sentence.

Sample answers:

1. Regular -re verbs: `Nous répondons au message ce soir.` — `répondre` is regular, and `nous` takes -ons.
2. `Depuis`: `Elle travaille ici depuis janvier.` — The work began in January and still continues, so the verb is present tense.
3. Spelling changes: `Nous mangeons au café.` — The extra e in `mangeons` keeps the g soft.
4. Shopping language: `J'achète une veste noire.` — `acheter` changes to `achète` with `je`, and `je` becomes `j'` before a vowel sound.

Mark yourself wrong if the verb ending does not match the subject, if `depuis` describes a finished past action, or if your shopping sentence has no actual shopping word or object.
:::


## C. Four-way variation

Choose one sentence from each lesson unit and rewrite it four ways:

1. change the subject;
2. make it negative;
3. turn it into a question;
4. change one meaningful detail.

:::answer
Worked example, starting from `Elle achète une chemise.`

1. Change the subject: `Nous achetons une chemise.` — `nous` drops the accent change and takes -ons.
2. Make it negative: `Elle n'achète pas une chemise.` — `ne` becomes `n'` before the vowel sound in `achète`.
3. Turn it into a question: `Est-ce qu'elle achète une chemise ?` — `que` becomes `qu'` before `elle`.
4. Change one meaningful detail: `Elle achète une veste.` — The verb stays the same because the subject did not change.

Your own starting sentence may be different. Check that each rewrite changes only the requested feature and that the subject change did not leave the old verb form behind.
:::


## D. Dictation and correction

Use text-to-speech to hear six examples from `lessons.md`. Write what you hear without looking. Correct in separate passes:

1. vocabulary;
2. verb form;
3. agreement or pronoun placement;
4. spelling and accents.

Do the dictation first, using this chapter's own examples as your audio. Then open the answers to check: they list six sentences worth dictating and the trap each one sets.

:::answer
Six sentences from this chapter that make good dictation material, and the trap each one sets:

1. `J'attends mon ami devant le magasin.` — `je` becomes `j'` before a vowel sound, and the final **s** in `attends` is silent.
2. `Nous habitons ici depuis trois ans.` — `depuis` uses the present tense because the living situation still continues.
3. `Nous commençons le cours à huit heures.` — the cedilla in `commençons` keeps the soft sound before **-ons**.
4. `Nous mangeons au restaurant avant de commencer les achats.` — `mangeons` needs an extra **e** before **-ons**.
5. `Elle achète une chemise et essaie une veste.` — both verbs have spelling changes: e to è, and y to i.
6. `Vous répondez depuis votre bureau ou vous envoyez un message plus tard ?` — `répondez` is regular -re with `vous`, and `envoyez` keeps **y** in the `vous` form.

Correct accents and stem changes in a separate pass. These are visual spelling problems even when the sentence sounds right.
:::

## E. Personal writing

Write a short store dialogue using one -re verb, three spelling-change verbs, a color, and depuis.

:::answer
Answers vary. A model dialogue:

**Client :** `Bonjour, j'attends ma sœur depuis dix minutes.`  
**Vendeuse :** `Pas de problème. Vous cherchez quelque chose ?`  
**Client :** `Oui, j'achète une veste noire et j'essaie cette chemise.`  
**Vendeuse :** `Votre sœur préfère quelle couleur ?`  
**Client :** `Elle préfère le bleu, mais nous commençons par la veste noire.`

Self-check:

- one -re verb: `j'attends`;
- three spelling-change verbs: `j'achète`, `j'essaie`, `préfère`, plus `commençons`;
- a color: `noire`, `bleu`;
- `depuis` with present tense: `j'attends ... depuis dix minutes`.

Mark it wrong if `depuis` is paired with a completed past action, if a color fails to agree where it should, or if your spelling-change verbs keep the wrong stem for their subject.
:::


## F. Oral recall

Explain each of the chapter's four main rules aloud in simple English, then give one French example from memory.

:::answer
1. **Regular -re verbs.** Remove -re and add -s, -s, no ending, -ons, -ez, -ent. Example: `Elle répond vite.`
2. **Depuis.** Use present tense for something that started before now and still continues. Example: `J'étudie le français depuis septembre.`
3. **Spelling-change -er verbs.** The verb is still an -er verb, but the stem changes to protect the sound or stress. Example: `Nous commençons à huit heures.`
4. **Shopping language.** Use the same verb patterns with real objects, colors, and preferences. Example: `J'achète une chemise bleue.`

If you can explain a rule but cannot produce a fresh French example, review that unit again. The goal is active production, not recognition only.
:::
